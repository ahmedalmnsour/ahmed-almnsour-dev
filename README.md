## التشغيل المحلّي

```bash
git clone https://github.com/ahmedalmnsour/ahmed-almnsour-dev.git
cd ahmed-almnsour-dev
npm install
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000) في المتصفّح.
